## 🎯 教學目標與核心素養
1. **認識情緒座標**：理解「活力度（身體電量高/低）」與「愉悅度（心裡舒服/不舒服）」兩大軸線。
2. **豐富情緒字彙**：從 4 個顏色象限共 36 張情緒卡中，精準命名自己當下的感受。
3. **學會表達句型**：透過五步驟鷹架（顏色 ➔ 卡片 ➔ 事件 ➔ 身體 ➔ 需求），溫柔而清晰地說出心裡話。
4. **情緒調節與同理**：同理他人的情緒狀態，掌握從紅區/藍區回到綠區/黃區的自我照顧方法。

## 二、表達心情的五大魔法咒語（句子鷹架）

請試著跟著以下 5 個魔法步驟，寫出或說出你今天的心情：

1. **第 1 步【定位象限】**：  
   「我現在在（ **紅色 ／ 黃色 ／ 藍色 ／ 綠色** ）象限，我的活力（ **高 ／ 低** ），心情感覺（ **舒服 ／ 不舒服** ）。」

2. **第 2 步【命名卡片】**：  
   「最符合我現在心情的是【 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; 】卡！」

3. **第 3 步【說出原因】**：  
   「因為今天發生了這件事：____________________________________________________________________  
   ____________________________________________________________________________________________」

4. **第 4 步【察覺身體】**：  
   「這時候我的身體訊號是：  
   [ &nbsp; ] 心跳很快 &nbsp;&nbsp; [ &nbsp; ] 喉嚨緊繃 &nbsp;&nbsp; [ &nbsp; ] 肚子痛痛的 &nbsp;&nbsp; [ &nbsp; ] 嘴角一直笑 &nbsp;&nbsp; [ &nbsp; ] 想趴著不動  
   其他身體感覺：____________________________________________________________________________」

5. **第 5 步【提出需求】**：  
   「我現在最希望可以：  
   [ &nbsp; ] 一個人安靜 5 分鐘 &nbsp;&nbsp;&nbsp;&nbsp; [ &nbsp; ] 得到一個擁抱 &nbsp;&nbsp;&nbsp;&nbsp; [ &nbsp; ] 找老師或同學聊一聊  
   [ &nbsp; ] 喝一口溫水深呼吸 &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp; [ &nbsp; ] 和大家一起玩球分享快樂！」

## 三、情緒偵探實戰題：情境大辨析

請閱讀情境，找出對應的象限與情緒卡，並想一想可以如何照顧自己：

| 校園生活情境 | 最可能的象限與情緒卡 | 我可以如何照顧自己或他人？ |
| :--- | :--- | :--- |
| **1. 下課想跟同學玩，同學卻說人滿了拒絕我加入。** | 藍區 ➔ **[ 孤單卡 / 難過卡 ]** | 找老師說心事，或找其他同學下棋、看書。 |

## 🧰 心情調節急救箱（從紅/藍區前往綠/黃區的五大魔法）
1. 🌬️ **4-7-8 緩慢深呼吸**：吸氣 4 秒 ➔ 憋氣 7 秒 ➔ 慢慢吐氣 8 秒，讓心跳降速。
2. 💧 **喝一口神奇溫開水**：慢慢感受水流過喉嚨，放鬆緊繃的胃部。
3. 🤝 **找心情神隊友訴說**：勇敢說出「我現在有點難過，可以陪我一下嗎？」。
4. 🎨 **把煩惱畫出來揉成球**：在紙上畫出暴風雨，然後用力揉成球丟掉！
5. 🌳 **望向走廊大樹伸個懶腰**：做 3 次擴胸運動，把體內的烏雲吹散。
