## 🏡 標題一：家庭型態大搜查（每題 5 分，共 25 分）

*🎯 學習重點：精準辨別小家庭、大家庭、單親家庭、隔代教養與新住民家庭。*

1. **( &nbsp;&nbsp;&nbsp; ) 爸爸、媽媽和小玉三個人住在一起，由父母共同照顧小玉，屬於哪種家庭？**  
   (A) 大家庭 &nbsp;&nbsp;&nbsp;&nbsp; (B) 小家庭（核心家庭） &nbsp;&nbsp;&nbsp;&nbsp; (C) 單親家庭 &nbsp;&nbsp;&nbsp;&nbsp; (D) 隔代教養  
   *👉 解析：(B) 小家庭由夫妻與未婚子女組成。*

2. **( &nbsp;&nbsp;&nbsp; ) 爺爺、奶奶、爸爸、媽媽、小明與叔叔三代人同住一間大房子，屬於什麼家庭？**  
   (A) 小家庭 &nbsp;&nbsp;&nbsp;&nbsp; (B) 大家庭（三代同堂） &nbsp;&nbsp;&nbsp;&nbsp; (C) 單親家庭 &nbsp;&nbsp;&nbsp;&nbsp; (D) 頂客家庭  
   *👉 解析：(B) 祖父母、父母與子女三代同住為大家庭。*

3. **( &nbsp;&nbsp;&nbsp; ) 小宇由媽媽一人細心撫養長大，母子倆感情深厚，這屬於什麼家庭型態？**  
   (A) 單親家庭 &nbsp;&nbsp;&nbsp;&nbsp; (B) 隔代教養家庭 &nbsp;&nbsp;&nbsp;&nbsp; (C) 大家庭 &nbsp;&nbsp;&nbsp;&nbsp; (D) 新住民家庭  
   *👉 解析：(A) 父或母單方撫養子女為單親家庭。*

4. **( &nbsp;&nbsp;&nbsp; ) 小晴的父母在外地工作，平時由外公、外婆在鄉下照顧生活，這屬於？**  
   (A) 小家庭 &nbsp;&nbsp;&nbsp;&nbsp; (B) 隔代教養家庭 &nbsp;&nbsp;&nbsp;&nbsp; (C) 單親家庭 &nbsp;&nbsp;&nbsp;&nbsp; (D) 大家庭  
   *👉 解析：(B) 祖父母或外祖父母照顧孫子女為隔代教養。*

5. **( &nbsp;&nbsp;&nbsp; ) 關於家庭型態，哪一個想法最正確？**  
   (A) 只有大家庭才幸福  
   (B) 每種家庭只要彼此相愛關懷，都是溫暖的家  
   (C) 單親家庭很奇怪  
   (D) 人數越少越好  
   *👉 解析：(B) 無論哪種型態，家人間的愛與支持最重要。*

## 🧹 標題二：成員分工小超人（每題 5 分，共 25 分）

*🎯 學習重點：理解男女平權家務分工、每位家庭成員各司其職與主動分擔責任。*

1. **( &nbsp;&nbsp;&nbsp; ) 關於家裡的家務分工，下列哪一種觀念是「最公平且適當」的？**  
   (A) 家事全部是媽媽一個人的責任  
   (B) 全家人依能力共同分擔家事  
   (C) 小孩只要讀書，完全不用做家事  
   (D) 男生不能進廚房  
   *👉 解析：(B) 家事是全家人的事，應按能力互相分擔。*

2. **( &nbsp;&nbsp;&nbsp; ) 身為國小三年級的學生，下列哪一件家事是我們可以「主動做好」的？**  
   (A) 爬到屋頂修水塔  
   (B) 整理自己的書包與打掃房間  
   (C) 使用瓦斯爐大火炒菜  
   (D) 操作危險割草機  
   *👉 解析：(B) 三年級學生應從打理自己生活與房間開始做起。*

3. **( &nbsp;&nbsp;&nbsp; ) 爸爸下班回來很辛苦，媽媽在煮飯，身為孩子的我最好怎麼做？**  
   (A) 躺在沙發上大叫要吃點心  
   (B) 主動幫忙擺碗筷、端菜或倒水搥背  
   (C) 假裝沒看見繼續玩電動  
   (D) 大聲抱怨肚子餓  
   *👉 解析：(B) 體貼長輩辛勞，主動分擔簡單家務。*

4. **( &nbsp;&nbsp;&nbsp; ) 家人之間如果有人生病或忙碌時，其他成員應該？**  
   (A) 互相推卸責任不理會 &nbsp;&nbsp;&nbsp;&nbsp; (B) 互相體諒並主動補位幫忙  
   (C) 大發脾氣責怪他生病 &nbsp;&nbsp;&nbsp;&nbsp; (D) 只顧自己吃飯  
   *👉 解析：(B) 家人互助補位能讓家庭運作更溫馨順暢。*

5. **( &nbsp;&nbsp;&nbsp; ) 為什麼全家人一起分擔家事很重要？**  
   (A) 可以讓一個人做全部的事  
   (B) 能讓家裡更整潔，增進家人凝聚力與責任感  
   (C) 為了領取高額零用錢  
   (D) 只是為了應付學校作業  
   *👉 解析：(B) 共同分擔能減輕負擔並促進家庭和樂。*

## 📷 標題三：家庭記憶時光機（每題 5 分，共 25 分）

*🎯 學習重點：探索家庭的成長演變、珍惜家庭生活照片與長輩的生活智慧傳承。*

1. **( &nbsp;&nbsp;&nbsp; ) 我們可以透過下列哪一種方式，探索自己家庭過去的成長故事？**  
   (A) 翻閱老家庭相簿或訪問長輩  
   (B) 亂丟家裡的舊照片  
   (C) 上網搜尋不相關的新聞  
   (D) 假裝自己沒有過去  
   *👉 解析：(A) 照片與長輩口述是認識家庭演變的最佳管道。*

2. **( &nbsp;&nbsp;&nbsp; ) 看到自己嬰兒時期的照片，知道家人細心抱著我餵奶，我們應該體會到？**  
   (A) 自己從小就很麻煩  
   (B) 家人撫育我們長大的辛勞與愛護  
   (C) 浪費很多相片紙  
   (D) 沒什麼特別的感覺  
   *👉 解析：(B) 體會長輩養育之恩並心存感激。*

3. **( &nbsp;&nbsp;&nbsp; ) 爺爺分享他小時候上學的生活與童玩，這代表了什麼意義？**  
   (A) 爺爺在炫耀  
   (B) 世代生活經驗與文化的珍貴傳承  
   (C) 現代人完全不需要聽  
   (D) 過去的生活很無聊  
   *👉 解析：(B) 長輩的生活經驗是寶貴的文化與歷史資產。*

4. **( &nbsp;&nbsp;&nbsp; ) 當家庭迎來新成員（如弟弟妹妹出生或小狗加入），家庭生活會有什麼轉變？**  
   (A) 充滿新的歡樂與需要學習分享照顧  
   (B) 討厭新成員搶走玩具  
   (C) 大家都不能說話  
   (D) 丟掉所有舊東西  
   *👉 解析：(A) 新成員帶來新角色，需練習分享與關懷。*

5. **( &nbsp;&nbsp;&nbsp; ) 珍惜家庭記憶最好的做法是？**  
   (A) 將全家出遊或節慶照片整理記錄並感謝家人  
   (B) 撕毀泛黃的老照片  
   (C) 抱怨家裡沒有豪宅  
   (D) 不跟家人拍照  
   *👉 解析：(A) 紀錄家庭點滴能加深彼此的美好回憶。*

## ❤️ 標題四：家人相處魔法心（每題 5 分，共 25 分）

*🎯 學習重點：掌握同理心溝通、孝順感恩長輩、以冷靜討論代替爭吵衝突。*

1. **( &nbsp;&nbsp;&nbsp; ) 當我想看卡通，而哥哥想看球賽發生爭執時，最好的解決方法是？**  
   (A) 搶奪遙控器大哭大鬧  
   (B) 猜拳決定或協議輪流觀看時間  
   (C) 把電視插頭剪斷  
   (D) 動手打哥哥  
   *👉 解析：(B) 協商與輪流是解決爭端的好方法。*

2. **( &nbsp;&nbsp;&nbsp; ) 當長輩說話提醒我們注意安全時，我們應有的禮貌態度是？**  
   (A) 翻白眼大聲頂撞  
   (B) 專心傾聽並溫和回答「謝謝提醒」  
   (C) 假裝耳朵聾了走開  
   (D) 甩門回房間  
   *👉 解析：(B) 尊重長輩善意提醒，保持良好態度。*

3. **( &nbsp;&nbsp;&nbsp; ) 下列哪一句話是家人溝通的「魔法降溫金句」？**  
   (A) 「都是你的錯啦！」  
   (B) 「我先聽你說，我們一起想辦法。」  
   (C) 「我再也不要理你了！」  
   (D) 「隨便你，反正我不管！」  
   *👉 解析：(B) 同理與傾聽能有效化解情緒。*

4. **( &nbsp;&nbsp;&nbsp; ) 家人之間表達愛與感謝最好的行動是？**  
   (A) 每天給長輩一個擁抱、主動說謝謝與問候  
   (B) 只在生日時要昂貴禮物  
   (C) 只要功課考好就不需要有禮貌  
   (D) 默默放在心裡永遠不說也不做  
   *👉 解析：(A) 用言語與行動把愛即時表達出來。*

5. **( &nbsp;&nbsp;&nbsp; ) 當自己不小心做錯事惹家人難過時，應該怎麼做？**  
   (A) 說謊推給弟妹  
   (B) 勇敢承認錯誤並誠懇道歉改善  
   (C) 逃跑離家出走  
   (D) 假裝沒這回事  
   *👉 解析：(B) 誠實負責才能贏得家人的信任。*
