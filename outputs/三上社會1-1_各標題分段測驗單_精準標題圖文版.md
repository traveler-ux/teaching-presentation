## 🌱 標題一：家庭成員的改變（每題 5 分，共 25 分）

*🎯 學習重點：理解家庭人數因出生、結婚、就學、離世等原因產生增減，體會家人彼此包容適應之重要。*

1. **( &nbsp;&nbsp;&nbsp; ) 下列哪一種情況會讓家裡的成員人數「增加」？**  
   (A) 叔叔結婚，嬸嬸搬進家裡一起生活  
   (B) 哥哥去外縣市讀大學住宿舍  
   (C) 姊姊出國打工實習  
   (D) 祖父搬到安養中心養病  
   *👉 解析：(A) 結婚或新生兒誕生會讓家庭同住人數增加。*

2. **( &nbsp;&nbsp;&nbsp; ) 小玉家最近迎來剛出生的妹妹，家裡變得很忙碌。身為大姊的小玉最好怎麼做？**  
   (A) 討厭妹妹搶走父母的注意力  
   (B) 主動幫忙拿尿布、保持安靜並體貼父母的辛苦  
   (C) 故意在房間大哭大鬧  
   (D) 拒絕跟妹妹住在同一個家  
   *👉 解析：(B) 體貼父母照顧嬰兒的辛勞，主動分擔簡單家務。*

3. **( &nbsp;&nbsp;&nbsp; ) 當家庭因為親人離世或長輩生病搬走而人數減少時，家庭成員應該？**  
   (A) 互相指責抱怨  
   (B) 互相關心安慰，一同分擔生活責任走過悲傷  
   (C) 假裝親人從沒存在過  
   (D) 不再跟其他家人說話  
   *👉 解析：(B) 人數減少時家人更需彼此扶持、互相安慰關懷。*

4. **( &nbsp;&nbsp;&nbsp; ) 關於家庭成員的改變，下列哪一項敘述是正確的？**  
   (A) 每個家庭的成員人數永遠不會改變  
   (B) 人數增加時要學會分享與接納，人數減少時要互相扶持  
   (C) 只要家庭成員有變動，家就毀了  
   (D) 只有小嬰兒出生才算家庭改變  
   *👉 解析：(B) 家庭成員增減是人生的常態，包容與愛是不變的關鍵。*

5. **( &nbsp;&nbsp;&nbsp; ) 媽媽收養了一隻流浪小狗，全家人一起照顧牠。這件事給家庭帶來了什麼意義？**  
   (A) 增加大家的家務負擔很討厭  
   (B) 迎來新的家庭夥伴，培養全家人的愛心與責任感  
   (C) 沒什麼特別意義  
   (D) 讓家裡變得很髒亂  
   *👉 解析：(B) 新生命夥伴能凝聚家庭情感，培養同理心與責任感。*

## ✍️ 標題二：命名的方式（每題 5 分，共 25 分）

*🎯 學習重點：認識姓名是個人代表與身分識別，理解從父/母姓、字輩排行、生辰祝福與長輩期許。*

1. **( &nbsp;&nbsp;&nbsp; ) 在臺灣的法律中，新生兒的姓氏可以如何決定？**  
   (A) 只能跟隨父親的姓氏  
   (B) 父母可以共同約定從父姓或從母姓  
   (C) 由里長抽籤決定  
   (D) 只能跟隨祖父的姓氏  
   *👉 解析：(B) 臺灣法律保障性別平權，父母可約定子女從父姓或從母姓。*

2. **( &nbsp;&nbsp;&nbsp; ) 許多長輩在為孩子取名字時，常會寄託什麼心意？**  
   (A) 長輩對孩子的祝福、健康長大或品德優良的期望  
   (B) 只是隨便翻報紙湊字  
   (C) 為了讓名字很難寫被處罰  
   (D) 為了在學校嘲笑同學  
   *👉 解析：(A) 名字往往凝聚了家族長輩最深切的愛與祝福。*

3. **( &nbsp;&nbsp;&nbsp; ) 堂兄弟的名字第二個字都是「建」（例如：建華、建國、建志），這種命名方式通常是依據？**  
   (A) 抽籤決定  
   (B) 家族的「字輩（輩分）」傳統  
   (C) 學校老師的規定  
   (D) 鄰居的想法  
   *👉 解析：(B) 許多漢人家族會按族譜字輩為同輩孩子命名。*

4. **( &nbsp;&nbsp;&nbsp; ) 有些人的名字取為「震宇」（期許氣宇非凡）或「詠晴」（期盼性格開朗如晴天），這代表名字具有？**  
   (A) 專屬的涵義與美麗的寓意  
   (B) 完全沒有意義的符號  
   (C) 讓人記不住的名字  
   (D) 恐嚇別人的作用  
   *👉 解析：(A) 每個名字都有獨特的文字涵義與期許。*

5. **( &nbsp;&nbsp;&nbsp; ) 名字對我們每一個人來說，最重要的價值是？**  
   (A) 拿來跟別人炫耀  
   (B) 代表個人的身分、尊嚴與長輩滿滿的愛  
   (C) 隨時可以丟掉的東西  
   (D) 只是為了應付考試  
   *👉 解析：(B) 姓名是個人身分的表徵與人格尊嚴的象徵。*

## 🪶 標題三：原住民的命名（每題 5 分，共 25 分）

*🎯 學習重點：理解臺灣原住民族群多元的命名文化（親子連名制、家屋名制、親從子名制與大自然意涵）。*

1. **( &nbsp;&nbsp;&nbsp; ) 泰雅族的知名作家「瓦歷斯·諾幹」，前面是自己的名字，後面是父親的名字「諾幹」。這種命名文化稱為？**  
   (A) 從母姓制  
   (B) 父子連名制（親子連名制）  
   (C) 羅馬拼音制  
   (D) 抽籤命名制  
   *👉 解析：(B) 泰雅族、賽夏族等常見父子連名制，記載父子血脈相承。*

2. **( &nbsp;&nbsp;&nbsp; ) 排灣族與魯凱族的命名文化中，常會把什麼名稱加入名字中以代表家族與傳承地位？**  
   (A) 學校名稱  
   (B) 「家屋名」或氏族名  
   (C) 寵物名字  
   (D) 縣市名稱  
   *👉 解析：(B) 排灣族、魯凱族重視家屋制度，姓名常冠上家屋名。*

3. **( &nbsp;&nbsp;&nbsp; ) 達悟族（雅美族）在有了孩子之後，長輩會改變自己的稱呼（如「夏曼」代表某人之父）。這種制度稱為？**  
   (A) 親從子名制  
   (B) 單一姓名制  
   (C) 國字翻譯制  
   (D) 永久固定制  
   *👉 解析：(A) 達悟族長輩隨子女出生改變稱謂，稱為親從子名制。*

4. **( &nbsp;&nbsp;&nbsp; ) 原住民族傳統姓名常蘊含什麼深厚的文化意義？**  
   (A) 記載祖先歷史、家族血脈與對大自然的崇敬  
   (B) 只是為了好玩隨便取的  
   (C) 跟漢人完全一模一樣沒有特色  
   (D) 為了讓別人念不出來  
   *👉 解析：(A) 原住民族姓名深刻連結祖靈、土地、自然與家族記憶。*

5. **( &nbsp;&nbsp;&nbsp; ) 看到原住民族同學使用羅馬拼音或傳統族名時，我們應該抱持什麼態度？**  
   (A) 覺得奇怪並亂取綽號  
   (B) 欣賞並尊重原住民優美的命名文化與身分認同  
   (C) 強迫同學改成漢人姓名  
   (D) 假裝沒看見  
   *👉 解析：(B) 尊重並欣賞多元文化，包容不同族群的命名傳統。*

## 🤝 標題四：尊重大家的姓名（每題 5 分，共 25 分）

*🎯 學習重點：落實姓名禮貌、正確發音稱呼他人、不取侮辱性綽號、建立尊重友善班級。*

1. **( &nbsp;&nbsp;&nbsp; ) 當班上有同學的名字發音比較特別或少見時，我們最正確的態度是？**  
   (A) 故意唸錯引全班大笑  
   (B) 認真向同學請教正確讀音並用心記住  
   (C) 直接幫他取難聽的綽號  
   (D) 拒絕叫他的名字  
   *👉 解析：(B) 虛心請教正確讀音是對他人最基本的尊重。*

2. **( &nbsp;&nbsp;&nbsp; ) 如果拿同學的姓名諧音取笑（例如把「黃國棟」叫成「果凍笨蛋」），會造成什麼影響？**  
   (A) 傷害同學的尊嚴，屬於不禮貌且不尊重的行為  
   (B) 讓班級氣氛變得更和諧  
   (C) 大家都很喜歡  
   (D) 展現自己的幽默感  
   *👉 解析：(A) 拿姓名取笑會造成言語傷害與霸凌，應嚴格禁止。*

3. **( &nbsp;&nbsp;&nbsp; ) 面對來自不同族群（如新住民、原住民）同學的姓名時，我們應該？**  
   (A) 保持開放與尊重，樂於了解其背後的文化故事  
   (B) 嘲笑對方的名字很長  
   (C) 排擠不跟他同組  
   (D) 到處張貼他的名字取笑  
   *👉 解析：(A) 認識同學名字背後的故事能增進彼此情誼。*

4. **( &nbsp;&nbsp;&nbsp; ) 當別人叫錯自己的名字時，最好的處理方式是？**  
   (A) 當場破口大罵並打人  
   (B) 和氣友善地提醒對方正確的讀音與寫法  
   (C) 默默回家哭泣不理人  
   (D) 故意去破壞對方的桌椅  
   *👉 解析：(B) 溫和清楚地澄清說明，彼此建立良好溝通。*

5. **( &nbsp;&nbsp;&nbsp; ) 「尊重每個人的姓名」是班級人際相處的重要守則，因為？**  
   (A) 姓名代表一個人的人格、尊嚴與家庭背景  
   (B) 只是因為校規有規定  
   (C) 怕被老師處罰罰站  
   (D) 為了獲得模範生獎狀  
   *👉 解析：(A) 尊重姓名就是尊重每個人的身分與尊嚴。*
