# 🎓 教學簡報專屬專案 (Teaching Presentation Project)

本專案專為國小導師設計，集成了三師爸 **SOIL 三大自動化簡報技能**。只需放入備課大綱或講義文字，AI 將自動生成高品質的教學簡報！

---

## 📁 專案資料夾結構

- **`inputs/`**：存放您的備課講義、課本大綱、Markdown 筆記檔。
- **`outputs/`**：存放 AI 自動生成完畢的 HTML 互動簡報或 PPTX 簡報檔。
- **`skills/`**：包含三大 SOIL 簡報技能與圖片打包工具。

---

## 🚀 三大簡報生成模式與指令

在 AI Agent 對話視窗中，切換到本資料夾（`C:\Projects\teaching-presentation\`）後，直接使用以下指令：

### 1. 🖨️ 模式一：可編輯 PowerPoint 簡報 (常用備課)
- **指令**：*「用 `soil-teaching-deck` 幫我把 inputs/範例_植物的器官與功能.md 做成可編輯的 PPT 簡報」*
- **輸出**：`outputs/植物的器官與功能.pptx`
- **特色**：AI 自動生成背景圖，文字保持為 PowerPoint 原生物件，可在 PPT 中雙擊修改內容。

### 🌐 2. 模式二：HTML 互動簡報 (大螢幕/直播教學)
- **指令**：*「用 `soil-html-deck` 幫我把 inputs/範例_植物的器官與功能.md 做成網頁互動簡報」*
- **輸出**：`outputs/植物的器官與功能.html`
- **特色**：支援網頁全螢幕播放、動態圖表與切換效果，跨裝置手機平板皆可看。

### 🎨 3. 模式三：SOIL 全圖美學簡報 (故事/極致視覺)
- **指令**：*「用 `soil-image-deck` 幫我把 inputs/範例_植物的器官與功能.md 做成全圖故事簡報」*
- **輸出**：`outputs/植物的器官與功能.pptx`
- **特色**：每頁皆為高質感 AI 主題圖像，搭配黃金文字排版。
